# PharmacyPatterns

Модуль №3. Учебный проект по паттернам проектирования на Java.

## Реализованные паттерны 

- Strategy — выбор способа доставки
- Builder — создание карточки товара
- Decorator — добавление дополнительных условий доставки
- Chain of Responsibility — последовательная проверка заказа
- Adapter — интеграция внешнего медицинского API
- Proxy — контроль доступа к проверке рецепта

## Технологии

- Java 17
- Maven

## Запуск

Запустить класс Main.
